Moving Your Expert Council into Optimizely Mark

How agents, skills and workflows map from Copilot / ChatGPT, and where CMP fits

2. Use case summary: Expert Council agents

  • Use case: Expert Council agents.
  • What it is: agents modeled on ~10 domain experts and their frameworks.
  • What it produces: the agents "debate" to produce positioning statements, GTM strategies and content briefs.
  • Reported impact: 2 months of work reduced to 2 days.

3. Recommended Expert Council design

BriefShared input: product, audience, goal, constraints
→
Expert agentsEach returns a position in the same output schema
→
Code stepMerges outputs into one structured payload
→
Debate round (optional)Experts see others' positions and rebut
→
Synthesizer agentResolves conflicts, produces the deliverable
→
CMPHuman review, then publish to the task

The synthesis step must be an agent, since code steps cannot call an LLM.

4. Step-by-step: build it

  1. Pick 2 or 3 experts to pilot, plus the Synthesizer.
  2. Gather the source material for each: instruction text, knowledge documents, and any actions or connectors.
  3. Draft each specialized agent in Mark chat. The agent builder shows a review card, flags ambiguous wording, suggests missing tools and generates test samples.
  4. Define one shared output schema so every expert's response can be merged and compared.
  5. Save shared guidance as skills (brand voice, brief template, house rules).
  1. Create a workflow agent: Agents > Your Agents > Add Agent > Workflow Agent.
  2. Add the expert agents, a code step to merge outputs, then the Synthesizer. Add conditions to route by deliverable type.
  3. Test with real briefs, compare against your current results, then tune instructions.
  4. Scale up to the full panel once the pilot is stable.
  5. Connect to CMP (optional): a CMP external-step webhook can trigger the workflow and mark the step complete when done.

5. Best practices

  • NarrowKeep each agent to one job.
  • ConsistentUse one output schema across experts.
  • Design firstBuild and test in chat before activating.
  • BoundedCap debate rounds to control time and cost (two is a good start).
  • ReviewedKeep a human approval step before publishing.
  • IncrementalPilot a small panel, then expand.

6. What to expect

There is no automated import of Copilot or ChatGPT agents into Mark, so the move is a rebuild. Instructions and knowledge port over directly; orchestration is re-created as a workflow agent. Knowledge files can be attached as context, folded into agent instructions, or exposed through a tool. External actions become Mark tools.
